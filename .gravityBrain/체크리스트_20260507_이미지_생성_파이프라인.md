# 체크리스트: 고화질 이미지 생성 및 자동 배포 파이프라인 구축

## 🎯 최종 목표
- [ ] 85개 마스터 프롬프트를 기반으로 고화질(Tier 1) 시각 결과물 자동 생성
- [ ] 생성된 이미지의 WebP 최적화 및 프로젝트 `public/` 디렉토리 자동 배치
- [ ] 데이터와 실제 이미지 파일 간의 100% 일치성 확보

## 🛠️ Phase 1: 이미지 생성 프로그램(Generator) 설계
- [ ] **환경 구성**: Python 기반 OpenAI(DALL-E 3) API 또는 Midjourney 자동화 모듈 셋업
- [ ] **데이터 파서 개발**: `lib/data/*.ts` 파일을 읽어 프롬프트와 변수값을 추출하는 로직 구현
- [ ] **이미지 생성 엔진**: 모델별(DALL-E 3, Midjourney) 생성 API 연동 및 결과물 다운로드 자동화
- [ ] **에러 핸들링**: 생성 실패 시 재시도(Retry) 및 로그 기록 시스템

## 🛠️ Phase 2: 최적화 및 후처리(Post-processing)
- [ ] **WebP 변환 엔진**: 대용량 PNG/JPG를 웹 최적화 포맷(WebP)으로 일괄 변환
- [ ] **자동 명명 시스템**: `source_prompt_hash` 또는 `slug` 기반의 파일명 매핑 자동화
- [ ] **품질 검수 툴**: 생성된 85개 이미지를 한눈에 확인하고 재생성을 트리거할 수 있는 간단한 대시보드 또는 로그 리포트

## 🛠️ Phase 3: 배포 및 통합
- [ ] **Asset 통합**: 생성된 파일을 `public/images/prompts/`에 일괄 이동
- [ ] **Vercel 동기화**: Git Push를 통한 최종 시각 결과물 실서버 반영
- [ ] **최종 QA**: 85개 상세 페이지에서 이미지가 깨짐 없이 노출되는지 전수 점검
